# How to contribute to OpenLab Module Builder

The OpenLab Module Builder project is maintained by the team behind the [City Tech OpenLab](https://openlab.citytech.cuny.edu/). We welcome contributions from the community of users.

## License

The project and its code is licensed under the GPLv3 or later. Contributions to the project must adhere to the same license.

## Reporting Issues

Feature requests and bug reports can be submitted using [the issue tracker on the project's GitHub repo](https://github.com/openlab-at-city-tech/openlab-module-builder/issues)

## Fixing bugs

When sending a pull request with a bug fix, please include a description of the bug and provide steps to reproduce.

## New features

Have an idea for new features? We recommend opening a GitHub issue first, in order to discuss feasibility, desirability, and implementation details with the team before starting work on a pull request.

## AI-assisted PRs

While we welcome the responsible use of AI-assisted tools to help with development, we ask that contributors keep the following guidelines in mind:

1. Be transparent and detailed about the use of AI tools in your work. This helps the maintainers to understand the reasoning behind implementation decisions, and it keeps to clarify attribution and adherence to the strictures of the GPL.

2. If you don't have the technical knowledge to explain what's happening in an AI-generated PR, please don't submit it. Better in that case to submit your ideas in a GitHub issue, and let the maintainers handle implementation.
