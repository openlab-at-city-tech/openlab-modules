A plugin to manage and display OpenLab Modules.

== Description ==

OpenLab Module Builder allows you to create, organize, and display modular content on your WordPress site. The plugin provides tools for building structured learning modules with support for import/export functionality and integrations with H5P and WWPE.

== Installation ==

1. Upload the `openlab-module-builder` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Begin creating modules from the WordPress admin.

== Frequently Asked Questions ==

= How do I create a module? =

After activating the plugin, you can create modules from the WordPress admin area.
